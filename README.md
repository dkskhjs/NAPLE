# NAPLE

메이플스토리 같은 횡스크롤 RPG에 노이타·매지카식 **스킬 조립**을 섞은 브라우저 게임입니다.
`index.html` 하나로 돌아가며 빌드 과정이 없습니다. 파일을 브라우저로 열면 바로 플레이할 수 있습니다.

## 조작

| 키 | 동작 |
| --- | --- |
| ← → | 이동 |
| Alt / Space / C | 점프 (↓ + 점프: 발판 아래로 내려가기) |
| ↑ ↓ | 밧줄 타기, 포털 이동·NPC 대화 (↑) |
| Ctrl / Z / X | 시전 (누르고 있으면 연사, ↑를 함께 누르면 위로 조준) |
| 마우스 클릭 | 마우스 방향으로 시전 |
| 1 ~ 4 | 지팡이 교체 |
| I / K / Tab | 마법서 (카드 배치, 카드 강화) |
| C | 캐릭터 (AP 분배, 장비) |
| J | 전직 (Lv.10, Lv.30) |
| Q / E | 빨간 포션 / 파란 포션 |
| M | 모든 소리 켜기/끄기 |
| N | 음악만 켜기/끄기 |
| P | 화면 효과: 도트 + 팔레트 / 도트 / 원본 |

터치 기기에서는 화면 버튼이 나타납니다.

## 성장

- **레벨**: 레벨마다 최대 HP·MP와 기본 마법 피해(+3%)가 오르고 AP 5를 받습니다.
- **AP**: INT(마법 피해 +1%), LUK(치명타 확률 +0.4%, 치명타 피해 +1%), WIS(최대 MP +5, MP 회복 +0.35/초). 메소를 내고 초기화할 수 있습니다.
- **유틸 카드**: 텔레포트 볼트, 스왑 볼트, 마법 벽, 발판 생성, 소환: 정령, 소환: 포탑, 보호막, 마나 회수, 힐(나는 회복, 적은 약한 피해). 투사체처럼 덱에 끼워 멀티캐스트·트리거·수정자와 섞입니다.
- **장비**: 모자(최대 MP), 로브(최대 HP), 신발(이동 속도), 반지 4칸. 일반·레어·에픽·유니크 등급에 따라 랜덤 옵션이 0~3개(반지는 +1) 붙습니다. 옵션: 최대 HP/MP, INT/LUK/WIS, MP 회복, 마나 소모 감소, 시전 지연 감소, 치명타, 마법 피해, 원소 피해, 이동 속도. 몬스터 드롭과 지팡이 장인 도르에게서 얻고, 로브 색이 캐릭터 색이 됩니다.
- **지팡이 고유 옵션**: 단계에 따라 0~3개. 원소 투사체 피해, 재충전 후 첫 카드 마나 0, 마나 절약, 멀티캐스트·트리거 피해, 관통 +1, 약한 유도, 치명타, 메아리 시전, MP 흡수, 투사체 크기.
- **카드 강화**: 가방의 같은 카드 3장을 합쳐 +1 (최대 +3). 단계마다 피해 +25%, 수정자 효과 +30%, 관통·반사 +1, 마나 −12%.
- **전직**: Lv.10에 화염 마법사·냉기 마법사·전격 마법사·독술사 중 하나, Lv.30에 같은 계열의 대마도사. 해당 원소 피해와 그 원소가 들어간 연계 피해가 오르고, 계열마다 고유 효과가 있습니다.

## 화면 효과

기본은 **도트 + 팔레트** 모드입니다. 월드를 약 480px 폭으로 그린 뒤 맵마다 뽑은 제한 팔레트와 4×4 베이어 디더링을 입히고, 정수 배율로 키워 도트 그래픽처럼 보이게 합니다. 이름표·데미지 숫자·HUD는 읽기 쉽도록 원래 해상도로 따로 그립니다.

## 스킬 시스템

- **지팡이**마다 슬롯 수, 시전 지연, 재충전, 퍼짐, 동시 시전 수가 다릅니다.
- 지팡이는 슬롯의 카드를 왼쪽부터 차례로 시전하고, 끝까지 쓰면 재충전합니다.
- 카드 종류
  - **투사체**(빨강): 매직 클로, 스파크, 에너지 볼, 파이어 애로우, 아이스 샤드, 썬더 볼트, 독안개, 메테오
  - **트리거**(보라): 트리거 볼트(적중 시), 타이머 오브(0.5초 후) — 다음 카드를 그 자리에서 시전
  - **수정자**(파랑): 데미지 증가, 가속, 반사, 사거리, 유도, 관통, 거대화, 치명타, 쾌속 시전, 정밀, 원소 부여, 폭발탄
  - **멀티캐스트**(금색): 더블, 트리플, 부채꼴, 쿼드
- 마법서 화면에서 지팡이별 **시전 순서 미리보기**를 볼 수 있습니다.

### 원소 연계

| 상태 | + 원소 | 결과 |
| --- | --- | --- |
| 빙결 | 화염 | 융해 (피해 ×2.5) |
| 빙결 | 전격 | 파쇄 (피해 ×2) |
| 화상 | 냉기 | 증기 폭발 |
| 화상 | 전격 | 과부하 폭발 |
| 중독 | 화염 | 독가스 폭발 |

## 맵

리프 마을(상점·지팡이 장인·안내원) → 초록 들판 → 깊은 숲 → 노을 사막 → 얼음 유적 → 강철 게의 둥지(보스)

진행 상황은 브라우저 localStorage에 자동 저장됩니다.

## 개발용

콘솔에서 `naple.warp(맵번호)`, `naple.give('meteor')`, `naple.state()`를 쓸 수 있습니다.

## 소리

- **효과음**: [Kenney](https://www.kenney.nl)의 Digital Audio, Impact Sounds, RPG Audio, Interface Sounds, Music Jingles(모두 CC0)에서 34개를 골라 MP3(모노 48kbps)로 변환해 `index.html`에 넣었습니다. 원본 변환 파일은 `assets/sfx/`에 있습니다. 원소마다 시전음이 다르고, 레벨업·전직·보스 격파에는 NES 징글이 나옵니다.
- **BGM**: 외부 파일 없이 WebAudio로 연주하는 칩튠입니다. 맵마다 조성·코드 진행·빠르기가 다르고, 멜로디는 맵별 고정 시드로 만들어 8마디를 반복합니다. 맵을 옮기면 크로스페이드로 바뀝니다.

## 그래픽 출처

지형·배경·몬스터·동전 스프라이트는 [Kenney](https://www.kenney.nl)의 **Pixel Platformer**(CC0)를 사용합니다.
원본 타일시트와 라이선스는 `assets/kenney/`에 있고, `index.html`에는 같은 이미지를 data URI로 넣어 파일 하나로 실행되게 했습니다.
플레이어와 NPC 마법사는 `assets/wizard/`의 스프라이트를 씁니다.
- `source.webp`: 받은 원본 시트 (체크무늬 배경이 그려진 이미지)
- `wizard_sheet_clean.png`: 원본을 도트 격자(8.33px = 1도트)로 다시 샘플링하고 배경을 뺀 240×123 시트. 맨몸, 모자·로브·후드 레이어, 지팡이, 아이템 포함
- `player_sheet.png`: 게임에서 쓰는 32×32 프레임 9장 (대기 2, 걷기 4, 시전 3). NPC는 같은 프레임의 로브 색만 바꿔 씁니다.

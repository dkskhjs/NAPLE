# NAPLE

메이플스토리 같은 횡스크롤 RPG에 노이타·매지카식 **스킬 조립**을 섞은 브라우저 게임입니다.
`index.html` 하나로 돌아가며 빌드 과정이 없습니다. 파일을 브라우저로 열면 바로 플레이할 수 있습니다.

## 조작

| 키 | 동작 |
| --- | --- |
| ← → | 이동 |
| Alt / Space / C | 점프 (↓ + 점프: 발판 아래로 내려가기) |
| ↑ ↓ | 밧줄 타기, 포털 이동·NPC 대화 (↑) |
| Ctrl / Z / X | 시전 (누르고 있으면 연사, ↑를 함께 누르면 위로 조준) |
| 마우스 클릭 | 마우스 방향으로 시전 |
| 1 ~ 4 | 지팡이 교체 |
| I / K / Tab | 마법서 (카드 배치, 카드 강화) |
| C | 캐릭터 (AP 분배, 장비) |
| J | 전직 (Lv.10, Lv.30) |
| L | 퀘스트 목록 |
| Q / E | 빨간 포션 / 파란 포션 |
| M | 모든 소리 켜기/끄기 |
| N | 음악만 켜기/끄기 |
| P | 화면 효과: 도트 + 팔레트 / 도트 / 원본 |

터치 기기에서는 화면 버튼이 나타납니다.

## 성장

- **레벨**: 레벨마다 최대 HP·MP와 기본 마법 피해(+3%)가 오르고 AP 5를 받습니다.
- **AP**: INT(마법 피해 +1%), LUK(치명타 확률 +0.4%, 치명타 피해 +1%), WIS(최대 MP +5, MP 회복 +0.35/초). 메소를 내고 초기화할 수 있습니다.
- **유틸 카드**: 텔레포트 볼트, 스왑 볼트, 마법 벽, 발판 생성, 소환: 정령, 소환: 포탑, 보호막, 마나 회수, 힐(나는 회복, 적은 약한 피해). 투사체처럼 덱에 끼워 멀티캐스트·트리거·수정자와 섞입니다.
- **장비**: 모자(최대 MP), 로브(최대 HP), 신발(이동 속도), 반지 4칸. 일반·레어·에픽·유니크 등급에 따라 랜덤 옵션이 0~3개(반지는 +1) 붙습니다. 옵션: 최대 HP/MP, INT/LUK/WIS, MP 회복, 마나 소모 감소, 시전 지연 감소, 치명타, 마법 피해, 원소 피해, 이동 속도. 몬스터 드롭과 지팡이 장인 도르에게서 얻고, 로브 색이 캐릭터 색이 됩니다.
- **지팡이 고유 옵션**: 단계에 따라 0~3개. 원소 투사체 피해, 재충전 후 첫 카드 마나 0, 마나 절약, 멀티캐스트·트리거 피해, 관통 +1, 약한 유도, 치명타, 메아리 시전, MP 흡수, 투사체 크기.
- **카드 강화**: 가방의 같은 카드 3장을 합쳐 +1 (최대 +3). 단계마다 피해 +25%, 수정자 효과 +30%, 관통·반사 +1, 마나 −12%.
- **전직**: Lv.10에 화염 마법사·냉기 마법사·전격 마법사·독술사 중 하나, Lv.30에 같은 계열의 대마도사. 해당 원소 피해와 그 원소가 들어간 연계 피해가 오르고, 계열마다 고유 효과가 있습니다.

## 몬스터

| 맵 | 몬스터 (특징) |
| --- | --- |
| 초록 들판 | 초록·파랑 꼬마, 분홍 외눈이(점프), 분열 젤리(죽으면 미니 젤리 2마리) |
| 깊은 숲 | 분홍 외눈이, 노랑 꼬마, 밤박쥐(날아다니며 급강하), 독침 꼬마(포물선 독 덩어리) |
| 노을 사막 | 드릴 드론, 사막 돌격병("!" 뒤 돌진), 폭탄 드론(머리 위에서 폭탄) |
| 얼음 유적 | 성난 상자, 서리 박쥐(냉기 저항, 얼음 탄), 방패 상자(정면 탄 80% 막음 — 뒤·폭발·운석·연쇄로 공략) |
| 강철 게의 둥지 | 강철 게 킹(점프 충격파, 포자 탄막, 불씨 꼬마 소환 — 불씨 꼬마는 화염 저항) |

일반 몬스터는 6% 확률로 **정예**(금빛, 크기 ×1.3, 체력 ×4, 피해 ×1.5, 경험치 ×4, 장비·카드 확정)로 나옵니다.

## 보스

사냥터 한가운데의 붉은 **보스 관문**(↑)으로 들어가는 전용 보스방이 있습니다. 보스방 왼쪽 포털로 나오면 관문 자리로 돌아옵니다. 보스를 잡을 때마다 보스 단계에 맞는 지팡이·장비 2개·카드 3장이 떨어지고, 다시 들어가면 보스가 새로 나옵니다.

| 보스 (관문 위치) | 체력 | 기믹 |
| --- | --- | --- |
| 젤리 여왕 (초록 들판, Lv.6+) | 4,000 | 점프 충격파, 젤리 비, 연속 점프. 체력 66%·33%에서 젤리 왕자 소환 |
| 고목 수호자 (깊은 숲, Lv.12+) | 9,000 | 발밑 경고 후 뿌리 솟구침, 나뭇잎 부채탄, 독침 꼬마 소환. **광합성**으로 회복하는 동안 화염을 맞히면 저지 |
| 모래 전갈왕 (노을 사막, Lv.18+) | 16,000 | 땅속 잠복(공격 불가) 후 발밑에서 솟구침, 독침 3연발, 돌진. 50% 이하에서 **모래폭풍** — 굴러오는 바위를 뛰어넘어야 함 |
| 빙결 군주 (얼음 유적, Lv.24+) | 26,000 | 공중 비행. **얼음 갑옷**이 있는 동안 피해 88% 감소 — 화염(전격은 조금)으로 깨면 12초간 기절·피해 ×1.25 후 재생. 고드름 비, 얼음 숨결, 급강하 |
| 혼돈의 마도사 (강철 게의 둥지, Lv.30+, 강철 게 킹 처치 후 개방) | 40,000 | 9초마다 **원소 장막** 교체 — 같은 원소는 흡수, 약점 원소는 ×1.6. 순간이동, 마력탄·부채탄·유성. 50% 이하에서 **환영** 2체(한 대면 사라짐) |

## 퀘스트

머리 위 `!`는 받을 수 있는 퀘스트, `?`는 완료 보고, `…`는 진행 중입니다. 동시에 5개까지 진행할 수 있고, 진행도는 화면 오른쪽 위와 L 키 목록에서 봅니다.

- **안내원 피오 (메인)**: 첫 사냥 → 마법서 펼치기 → 갈라지는 골칫거리 → 깊은 숲으로 → 전직의 길 → 노을 너머 → 얼음 유적의 수수께끼 → 강철 게 킹
- **마법상점 루나 (반복)**: 마력 가루 모으기, 원소 연계 5회
- **지팡이 장인 도르 (반복)**: 헬멧 조각, 드론 부품, 정예 3마리

## 화면 효과

기본은 **도트 + 팔레트** 모드입니다. 월드를 약 480px 폭으로 그린 뒤 맵마다 뽑은 제한 팔레트와 4×4 베이어 디더링을 입히고, 정수 배율로 키워 도트 그래픽처럼 보이게 합니다. 이름표·데미지 숫자·HUD는 읽기 쉽도록 원래 해상도로 따로 그립니다.

## 스킬 시스템

- **지팡이**마다 슬롯 수, 시전 지연, 재충전, 퍼짐, 동시 시전 수가 다릅니다.
- 지팡이는 슬롯의 카드를 왼쪽부터 차례로 시전하고, 끝까지 쓰면 재충전합니다.
- 카드 종류
  - **투사체**(빨강): 매직 클로, 스파크, 에너지 볼, 파이어 애로우, 아이스 샤드, 썬더 볼트, 독안개, 메테오
  - **트리거**(보라): 트리거 볼트(적중 시), 타이머 오브(0.5초 후) — 다음 카드를 그 자리에서 시전
  - **수정자**(파랑): 데미지 증가, 가속, 반사, 사거리, 유도, 관통, 거대화, 치명타, 쾌속 시전, 정밀, 원소 부여, 폭발탄
  - **멀티캐스트**(금색): 더블, 트리플, 부채꼴, 쿼드
- 마법서 화면에서 지팡이별 **시전 순서 미리보기**를 볼 수 있습니다.

## 맵

리프 마을(상점·지팡이 장인·안내원) → 초록 들판 → 깊은 숲 → 노을 사막 → 얼음 유적 → 강철 게의 둥지(보스)

진행 상황은 브라우저 localStorage에 자동 저장됩니다.

## 개발용

콘솔에서 `naple.warp(맵번호)`, `naple.give('meteor')`, `naple.state()`를 쓸 수 있습니다.

## 소리

- **효과음**: [Kenney](https://www.kenney.nl)의 Digital Audio, Impact Sounds, RPG Audio, Interface Sounds, Music Jingles(모두 CC0)에서 34개를 골라 MP3(모노 48kbps)로 변환해 `index.html`에 넣었습니다. 원본 변환 파일은 `assets/sfx/`에 있습니다. 원소마다 시전음이 다르고, 레벨업·전직·보스 격파에는 NES 징글이 나옵니다.
- **BGM**: `assets/bgm/`의 곡을 장면마다 재생합니다 (96kbps, 음량 -16 LUFS로 맞춤). 장면을 옮기면 페이드로 바뀌고, 다시 오면 이어서 재생합니다.
  | 장면 | 곡 |
  | --- | --- |
  | 타이틀 | the_map_unfolds |
  | 리프 마을 | path_to_the_great_oak |
  | 초록 들판 | first_light_in_the_valley |
  | 깊은 숲 | lanterns_in_the_canopy |
  | 얼음 유적 | under_permafrost |
  | 강철 게의 둥지 | halls_of_permafrost |

  곡이 없는 장면(노을 사막)은 WebAudio 칩튠 시퀀서로 연주합니다. 곡 파일은 `index.html` 옆의 `assets/bgm/`에서 읽으므로 폴더째 두어야 합니다.

## 그래픽 출처

지형·배경·몬스터·동전 스프라이트는 [Kenney](https://www.kenney.nl)의 **Pixel Platformer**(CC0)를 사용합니다.
원본 타일시트와 라이선스는 `assets/kenney/`에 있고, `index.html`에는 같은 이미지를 data URI로 넣어 파일 하나로 실행되게 했습니다.
NPC(루나·피오·도르)는 `assets/npc/`, 노을 사막의 땅·발판·줄사다리·배경·소품은 `assets/desert/`의 시트를 씁니다. 두 시트 모두 받은 이미지(`source.webp`)를 도트 격자(11.47px = 1도트)로 다시 샘플링하고, 바깥 테두리와 이어진 체크무늬만 지워 외곽선 안쪽 회색(수염 등)은 남겼습니다. 사막 조각 44개는 `atlas.png`/`atlas.json`에 모았습니다.
리프 마을·초록 들판·깊은 숲·얼음 유적의 집·나무·덤불·버섯·얼음 결정·아치 같은 소품은 `assets/props/`에 있습니다. 받은 시트가 512px 축소본이라 땅과 발판은 Kenney 타일을 유지하고, 소품만 잘라 2배로 그립니다(도트 모드에서 원본 1픽셀 = 화면 도트 1칸).
플레이어 마법사는 `assets/wizard/`의 스프라이트를 씁니다.
- `source.webp`: 받은 원본 시트 (체크무늬 배경이 그려진 이미지)
- `wizard_sheet_clean.png`: 원본을 도트 격자(8.33px = 1도트)로 다시 샘플링하고 배경을 뺀 240×123 시트. 맨몸, 모자·로브·후드 레이어, 지팡이, 아이템 포함
- `player_sheet.png`: 게임에서 쓰는 32×32 프레임 9장 (대기 2, 걷기 4, 시전 3).
